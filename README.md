# Live TV & Stream Proxy Web Application

একটি সিক্যুরড এবং অটোমেটেড স্ট্রিমিং ওয়েব অ্যাপ্লিকেশন, যা ক্লাউডফ্লাওয়ার ওয়ার্কার (Cloudflare Worker) এবং GitHub Pages-এর মাধ্যমে পরিচালিত হয়।

## 🚀 বৈশিষ্ট্যসমূহ (Features)
* **সিকিউরড প্রক্সি:** ক্লাউডফ্লাওয়ার ওয়ার্কারের মাধ্যমে ভিডিও ও লাইভ স্ট্রিম সুরক্ষিত থাকে।
* **অটোমেটেড আপডেট:** GitHub Actions ব্যবহার করে প্রজেক্টের লিংক ও ডেটা প্রতিদিন স্বয়ংক্রিয়ভাবে আপডেট হয়।
* **সুরক্ষা ব্যবস্থা:** সাইটের কোড কপি বা রাইট-ক্লিক রোধ করার জন্য প্রয়োজনীয় প্রোটেকশন যুক্ত করা আছে।
* **রেসপন্সিভ ডিজাইন:** যেকোনো ডিভাইসে সাবলীলভাবে কাজ করার উপযোগী লেআউট।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)
* **Frontend:** HTML5, CSS3, JavaScript, Hls.js
* **Backend / Security:** Cloudflare Workers
* **Automation:** GitHub Actions

## ⚙️ সেটআপ নির্দেশিকা (Setup Guide)
1. এই রিপোজ়িটরি ফর্ক বা ক্লোন করুন।
2. Cloudflare Worker-এ ব্যাকএন্ড কোড ডিপ্লয় করুন।
3. `data.json` বা প্রয়োজনীয় ফাইলে আপনার স্ট্রিম লিংকগুলো যুক্ত করুন।
4. GitHub Pages থেকে সাইটটি লাইভ করুন।
